# Codex 작업 프롬프트 — Day03 외부 조도센서 원고·이미지 구현

기존 **여량초 6학년 「내일을 바꾸는 미래기술 연구소」 학생용 디지털 교과서**에 Day03을 구현한다.

새 프로젝트나 별도 사이트를 만들지 말고, 현재 프로젝트의 구조·디자인·저장 방식·Day01~02 구현을 유지한 채 Day03 관련 부분만 추가·수정한다.

## 1. 작업 전 확인

다음 자료를 먼저 읽고 현재 소스와 비교한다.

1. 최신 기초기획안과 수업제작 파이프라인 기준문서
2. 첨부한 `day03_student_content_external_light_sensor_revised.md`
3. 기존 Day01·Day02의 `research-days.js`, `app.js`, `styles.css`, `index.html`
4. 현재 학생 기록 저장·복원·완료 판정 구조
5. 아래 첨부 이미지 7개

`day03_student_content_external_light_sensor_revised.md`의 학생용 문구를 **확정 원고**로 사용한다. 맞춤법이나 표현을 임의로 줄이거나 다시 쓰지 않는다. 기존 구현 제약 때문에 변경이 꼭 필요하면 먼저 변경 이유와 대상 문장을 보고한다.

기존 작업 트리의 사용자 변경사항을 보존하고 Day03과 관계없는 코드는 수정하지 않는다.

## 3. Day02와 Day03의 조도센서 구분

아래 구분이 학생 화면 전체에서 일관되어야 한다.

- Day02: 마이크로비트의 **내장 조도센서**, 값 범위 `0~255`
- Day03: Sensor:Edge의 **P1에 연결한 외부 조도센서**, 아날로그 입력값 범위 `0~1023`
- Day02에서 이어 쓰는 것: `측정 → 기준 설정 → 조건 판단`이라는 방법
- Day03에서 새로 정하는 것: 외부 조도센서의 어두울 때 값, 밝을 때 값, 새 기준값

다음과 같은 오래된 문구나 의미는 제거한다.

- Day02 기준값을 Day03에서 그대로 사용한다는 설명
- Day02에서도 외부 조도센서가 P1에 연결되어 있었다는 설명
- 외부 조도센서와 서보모터를 마이크로비트의 3V·GND에 직접 연결한다는 설명

Day03의 실제 연결 기준은 다음으로 통일한다.

- Sensor:Edge P1: 외부 조도센서
- Sensor:Edge P2: 서보모터
- P1 외부 조도센서: 센서와 포트의 `S·V·G` 표시를 맞춰 연결
- P2 서보모터: 노랑→S, 빨강→V, 갈색→G

센서 모듈에 따라 밝을 때 숫자가 커지는 방향이 다를 수 있으므로, 학생이 밝음·어두움 값을 실제로 측정한 뒤 `크다/작다` 조건을 정하게 한다.

## 5. 이미지 표시 기준

각 이미지는 `<figure>`와 `<img>`를 사용하고 필요한 경우 짧은 `<figcaption>`을 둔다.

- 원본 비율 유지
- `max-width: 100%`, `height: auto`
- 모바일과 학생용 노트북 화면에서 가로 스크롤이 생기지 않게 처리
- 생성형 인포그래픽 2개는 본문 폭을 충분히 사용
- MakeCode 화면 이미지는 글자를 읽을 수 있는 크기로 표시
- 현재 프로젝트에 이미지 확대 기능이 있다면 같은 방식을 재사용
- 장식용이 아니므로 구체적인 대체텍스트 제공

대체텍스트는 다음 의미를 포함한다.

1. 일반 모터의 연속 회전과 서보모터의 각도 이동 비교
2. 외부 조도센서 P1, 서보모터 P2, S·V·G 연결 안내
3. MakeCode 고급·핀 메뉴에서 서보 출력 블록을 찾는 화면
4. P2 서보모터를 30도·90도·150도로 움직이는 코드
5. MakeCode 고급·핀 메뉴에서 아날로그 입력 블록을 찾는 화면
6. P1 아날로그 입력값을 계속 표시하는 코드
7. P1 값이 기준보다 클 때 P2를 30도, 아니면 150도로 움직이는 코드

## 6. 화면 구성 순서

Day03은 다음 순서를 유지한다.

1. Day02의 내장 조도센서 연구 복원
2. Day03에서 외부 조도센서로 바뀐다는 점 확인
3. 일반 모터와 서보모터 비교
4. Sensor:Edge와 S·V·G의 역할 이해
5. P1 외부 조도센서와 P2 서보모터 연결
6. 서보모터 30°·90°·150° 단독 시험
7. P1 외부 조도센서의 밝음·어두움 값 측정
8. 두 값 사이에서 Day03의 새 기준값 결정
9. 센서 조건과 서보 각도 결합
10. 밝음·어두움 두 상태 시험, 오류 수정, 영상 증거와 연구 기록

Block07의 서보 블록 위치 이미지와 Block08의 아날로그 입력 블록 위치 이미지는 처음부터 모두 노출하지 말고, 기존 프로젝트의 도움말·펼치기 UI가 있으면 그 구조를 재사용한다.

## 7. 입력·저장·복원

기존 데이터 구조와 이름 규칙을 먼저 확인한 뒤 Day03 기록 필드를 추가한다. 최소한 다음 값이 학생별로 저장·복원되어야 한다.

- 외부 조도센서의 어두울 때 측정값
- 외부 조도센서의 밝을 때 측정값
- Day03에서 새로 정한 기준값
- 밝을 때와 어두울 때 숫자가 커지는 방향 선택
- 첫 번째 서보 각도
- 두 번째 서보 각도
- 어두운 상태 시험 결과
- 밝은 상태 시험 결과
- 학생이 직접 바꾼 항목
- 퀴즈 응답과 연구 기록
- 촬영한 작동 영상 또는 기존 영상 저장 구조와의 연결

숫자 입력은 허용 범위를 검증한다.

- P1 아날로그 측정값과 기준값: `0~1023`
- 서보 각도: `0~180`
- 기본 예시는 30°와 150°로 제공하되 학생이 변경할 수 있게 한다.

자동 저장·수동 저장·새로고침 복원은 기존 Day01~02 방식과 동일하게 동작해야 한다.

## 8. 완료 판정

기존 프로젝트의 완료 상태 자료형과 명명 방식을 그대로 사용하여 다음 의미를 구현한다.

- `minimumCompleted`: P1 외부 조도센서의 조건 변화로 P2 서보모터 위치가 한 번 이상 실제로 달라졌다고 기록
- `basicCompleted`: 최소 수행 + 밝음·어두움 측정값 2개 + 새 기준값 + 두 상태 시험 완료
- `advancedCompleted`: 기본 완성 + 기준값·각도·조건 방향·센서 위치 중 하나를 학생이 직접 변경
- 연구일 최종 완료: 최소 수행 + 퀴즈 완료 + 최소 연구기록 완료

영상 업로드 장애만으로 최소 수행이 막히지 않도록 기존 영상 보완 구조를 재사용한다.

## 9. 구현 제약

- Day01·Day02 콘텐츠와 판정식을 변경하지 않는다.
- 기존 공통 렌더링 구조를 우회하는 Day03 전용 대규모 하드코딩은 피한다.
- 학생 화면에 강사용 시간표·개발 메모·필드명·정답 데이터가 노출되지 않게 한다.
- 카드와 중첩 테두리를 불필요하게 늘리지 않는다.
- 이미지가 없어도 텍스트만으로 핵심 연결을 확인할 수 있어야 하지만, 첨부 이미지 7개는 정상 환경에서 모두 표시되어야 한다.
- Apps Script나 Google Sheets 구조 변경이 꼭 필요하지 않다면 수정하지 않는다. 필요하면 변경 이유와 영향 범위를 먼저 보고한다.
