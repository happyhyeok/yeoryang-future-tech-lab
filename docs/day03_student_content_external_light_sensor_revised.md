# Block07 · 프로그램으로 움직임 만들기

## 1. 모터와 서보모터는 무엇이 다를까요?

모터는 전기를 이용해 **움직임을 만드는 장치**입니다.

일반 모터는 주로 계속 빙글빙글 돌리는 데 사용합니다.

**서보모터**는 조금 다릅니다.

> **“이 위치로 움직여!”라고 프로그램에서 각도를 정해 줄 수 있는 모터입니다.**

예를 들어

- 30° → 한쪽
- 90° → 가운데
- 150° → 반대쪽

처럼 위치를 정할 수 있습니다.

**[이미지 01 삽입]**  
일반 모터와 서보모터의 차이 + 서보 30°·90°·150° 위치

---

## 2. 외부 장치는 어떻게 마이크로비트와 연결될까요?

오늘은 외부 조도센서와 서보모터를 **Sensor:Edge**에 연결합니다.

Sensor:Edge는 마이크로비트와 외부 장치를 쉽게 연결할 수 있도록 핀과 전원 자리를 정리해 주는 연결 보드입니다.

각 연결 자리에는 세 가지 표시가 있습니다.

### V · 전원

센서와 서보모터가 작동하는 데 필요한 전기를 보냅니다.

### G · 전기가 돌아오는 길

V와 G가 함께 연결되어야 장치가 전기를 사용할 수 있습니다.

### S · 신호

장치와 마이크로비트가 정보를 주고받는 길입니다.

- 조도센서의 S선: 측정한 빛의 값을 마이크로비트로 보냅니다.
- 서보모터의 S선: 어느 위치로 움직일지 명령을 받습니다.

간단히 기억하세요.

> **V·G = 장치가 작동할 전기의 길**  
> **S = 측정값이나 명령이 오가는 길**

---

## 3. 외부 조도센서와 서보모터를 연결합니다

### ① 먼저 전원을 분리합니다

선을 꽂거나 바꿀 때에는 먼저 마이크로비트의 USB 케이블이나 배터리를 분리합니다.

### ② 외부 조도센서를 P1에 연결합니다

지난 연구의 내장 조도센서는 선을 연결하지 않았지만, 오늘의 외부 조도센서는 Sensor:Edge의 **P1**에 연결해야 합니다.

센서와 케이블에 표시된 `S`, `V`, `G`가 P1의 같은 글자와 맞는지 확인합니다.

- 센서 신호 → P1의 **S**
- 센서 전원 → P1의 **V**
- 센서 접지 → P1의 **G**

센서 케이블의 색은 부품에 따라 다를 수 있으므로 색만 보고 연결하지 말고 `S·V·G` 표시를 확인합니다.

### ③ 서보모터를 P2에 연결합니다

서보모터는 외부 조도센서와 다른 핀인 **P2**에 연결합니다.

- **노란색 → P2의 S**
- **빨간색 → P2의 V**
- **갈색 → P2의 G**

> **P1 = 외부 조도센서**  
> **P2 = 서보모터**

### ④ 연결을 확인한 뒤 전원을 다시 연결합니다

다음 세 가지를 확인합니다.

- P1과 P2가 바뀌지 않았나요?
- S·V·G의 위치가 맞나요?
- 커넥터가 비뚤어지거나 억지로 꽂히지 않았나요?

**[이미지 02 삽입]**  
실제 Sensor:Edge 중심 배선 안내  
왼쪽 외부 조도센서 → P1  
오른쪽 서보모터 → P2  
P1의 S·V·G 표시와 P2의 노랑 S / 빨강 V / 갈색 G 확대

# Block08 · 외부 조도센서가 판단하고 서보모터가 움직이게 하기

## 6. 외부 조도센서의 값을 먼저 확인합니다

서보모터와 합치기 전에 P1의 외부 조도센서가 빛을 제대로 읽는지 먼저 확인합니다.

MakeCode에서 **P1의 아날로그 값을 읽는 블록**을 찾습니다.

외부 조도센서의 값은 보통 `0~1023` 범위에서 나타납니다. 지난 시간의 내장 조도센서 값은 `0~255` 범위였기 때문에 두 숫자를 직접 비교하거나 지난 기준값을 그대로 사용할 수 없습니다.

**[이미지 05 삽입]**  
MakeCode의 `고급 → 핀`에서 `아날로그 입력 값` 블록을 찾는 화면

찾은 블록의 핀을 **P1**로 바꾸고, 계속 값을 확인하는 코드를 만듭니다.

**[이미지 06 삽입]**  
P1 아날로그 값을 계속 읽어 숫자로 확인하는 실제 MakeCode 블록

### 두 상태를 측정합니다

| 시험 상태 | 측정값 |
| --- | ---: |
| 외부 조도센서를 손으로 가렸을 때 | `{어두울 때 값}` |
| 외부 조도센서에 빛이 잘 들어올 때 | `{밝을 때 값}` |

### 무엇을 발견했나요?

○ 밝을 때 숫자가 더 컸습니다.  
○ 어두울 때 숫자가 더 컸습니다.  
○ 숫자가 거의 달라지지 않았습니다.

센서 모듈에 따라 숫자가 커지는 방향이 다를 수 있습니다. 먼저 실제 값을 확인한 뒤 조건의 `크다` 또는 `작다` 방향을 정합니다.

숫자가 거의 달라지지 않는다면 P1 연결과 센서 방향을 다시 확인합니다.

# 예상과 다르다면 연구원이 확인할 순서

## ① 외부 조도센서 연결 확인

외부 조도센서가 P1에 연결되어 있는지 확인합니다. P1의 S·V·G와 센서의 S·V·G가 맞는지도 봅니다.

## ② 센서값 확인

P1의 값이 밝고 어두울 때 실제로 달라지는지 봅니다.

## ③ 조건 확인

오늘 새로 정한 기준값을 사용했는지, `크다 / 작다`의 방향이 측정 결과와 맞는지 봅니다.

## ④ 서보모터 연결 확인

P2의 선을 다시 봅니다.

- 노랑 → S
- 빨강 → V
- 갈색 → G

## ⑤ 각도 확인

두 서보 각도가 서로 다른 숫자인지 봅니다.

## ⑥ 다시 시험

한 곳을 고쳤다면 처음부터 다시 만들지 말고 **바꾼 부분만 다시 시험**합니다.

> **확인 → 판단 → 수정 → 다시 시험**

서보모터가 계속 떨거나 이상한 소리가 난다면 억지로 잡지 말고 전원을 분리한 뒤 강사에게 알려 주세요.

# 오늘의 성공 확인

## 최소 성공

> **P1 외부 조도센서의 조건이 바뀌었을 때 P2 서보모터의 위치가 실제로 바뀌었다.**

## 기본 완성

> **외부 조도센서의 밝고 어두운 값을 측정해 새 기준값을 정하고, 두 상태에서 예상한 움직임이 나타나는지 확인했다.**

## 더 해보기

기본 연구를 끝냈다면 하나를 선택합니다.

- 서보모터 각도를 내가 원하는 값으로 바꾸기
- 외부 조도센서 기준값을 바꾸고 결과 비교하기
- 움직임의 방향을 반대로 만들기
- 외부 조도센서를 장치에서 빛을 잘 감지할 위치로 옮겨 보기
- 내가 만들 미래 장치에서는 이 움직임을 어디에 사용할지 생각하기
- **무선통신 기술 카드**에 도전하기

무선통신은 오늘 반드시 해야 하는 활동이 아닙니다.

외부 조도센서의 상태가 바뀌고 서보모터가 움직이는 모습을 짧게 촬영합니다.

영상에는 가능하면 다음 세 모습이 모두 보이게 합니다.

1. P1에 연결된 외부 조도센서
2. 센서를 밝게 하거나 어둡게 바꾸는 모습
3. P2 서보모터의 위치가 바뀌는 모습

> 완벽하게 꾸민 작품보다 **실제로 조건에 따라 움직인다는 증거**가 중요합니다.

# 오늘의 퀴즈

### 1. 지난 시간과 오늘 사용한 조도센서의 차이로 알맞은 것은?

① 지난 시간은 내장 조도센서, 오늘은 P1에 연결한 외부 조도센서를 사용한다.  
② 두 시간 모두 P1 외부 조도센서만 사용한다.  
③ 오늘은 조도센서를 사용하지 않는다.

**정답: ①**

---

### 2. 외부 조도센서를 P1에 연결할 때 확인할 것은 무엇인가요?

① S·V·G가 같은 표시와 연결되었는지 확인한다.  
② 선의 길이만 확인한다.  
③ P1과 P2에 동시에 연결한다.

**정답: ①**

---

### 3. Day02의 기준값을 오늘 그대로 사용하지 않는 이유는 무엇인가요?

① 센서의 종류와 값의 범위가 달라서 오늘 다시 측정해야 하기 때문이다.  
② 서보모터에는 숫자가 필요 없기 때문이다.  
③ 지난 연구는 오늘 연구와 관계가 없기 때문이다.

**정답: ①**

---

### 4. 서보모터의 S선은 어떤 역할을 하나요?

① 어느 위치로 움직일지 명령 신호를 전달한다.  
② 빛을 측정한다.  
③ 사진을 저장한다.

**정답: ①**

---

### 5. 예상한 것과 실제 움직임이 다르다면 가장 알맞은 연구 방법은?

① 모두 지우고 처음부터 다시 만든다.  
② 연결·센서값·조건·각도를 확인하고 필요한 부분을 고쳐 다시 시험한다.  
③ 작동했다고 기록하고 넘어간다.

**정답: ②**
