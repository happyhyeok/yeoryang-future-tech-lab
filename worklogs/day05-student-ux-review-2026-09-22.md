# Day05 학생 UX 정리 — 2026-09-22

## 변경 목적
- 관찰 연습과 독립 관찰을 나누고, 중복 질문 및 A1~A4 내부 코드를 학생 화면에서 없앤다.
- 불편 내용과 완성된 문제 정의문을 분리하고, 기존 저장 기록은 초기 로드만으로 변경하지 않는다.

## 구현
- A1 첫 답을 선택형으로 바꾸고 기존 자유입력 답은 화면과 상태에 보존한다. A1/A2의 후속 질문은 해당 응답 버튼 바로 위에 한 번만 표시한다.
- A1/A2는 `함께 연습해요`, A3/A4는 `이제 내가 찾아봐요`로 분리한다. A3/A4는 학생용 설명만 표시하고 이미지를 유지한다.
- `targetUser`, `inconvenience`, `problemDefinition`, `problemDefinitionEdited`를 사용한다. 사람과 불편을 입력하면 완성 문장을 만들고, 학생이 문장을 직접 편집한 뒤에는 사람/불편 입력이 해당 문장을 덮어쓰지 않는다.
- 기존 불편만 든 `problemDefinition`은 표시용 fallback으로 사용한다. 학생이 새 값을 수정/선택하기 전에는 기존 저장 객체를 migration하지 않는다.
- 완료 문장과 불편 값을 기존 `dayStateJson` 및 DayRecord 호환 필드에 반영한다. Day06은 Day05의 완성 문장을 불러오고, 레거시 기록은 가능한 경우 읽기 시점에 안전하게 문장화한다.
- 현실 확인은 질문별 `예`/`아직` 버튼으로 바꾸고, 새 응답의 미선택 상태(null)와 아니오(false)를 구분한다. 기존 source별 배열 호환을 유지한다.
- `3분 불편 탐정`을 `교실 불편 탐정`으로 바꾸고 3분 관찰 안내를 더한다(타이머는 추가하지 않음).
